## Replace a campaign image

Replace the same-named file in `assets/source/` with an approved source, then run `npm run prepare:images`. The script writes widths 320, 480, 768, 1024, 1440 and 1920 as WebP, plus a fallback. These widths match `next.config.ts` and `lib/image-loader.ts`. Delete the superseded input if its extension changes, so two inputs cannot target one basename.

Adjust `imageAlt` and anatomy coordinates in `data/products.ts` when the actual design changes. Layouts use independent aspect ratios, not source dimensions. For genuinely different mobile compositions, add a separate approved crop and use a picture/media source rather than sacrificing important product detail.

## Colourways

The four CSS colour tokens are previews, not guaranteed production shades. Add approved image entries to each product's colourways in `data/products.ts`. Images in the `/images/` namespace must have the six width variants generated by the script.

## Wordmark

Replace `public/brand/wordmark.webp` with an approved wordmark of the same approximate aspect ratio and use the shared BrandLogo component. Refresh the banner and favicon separately when the identity changes. Do not invent or replace the symbol silently.

## Fonts

Barlow Condensed (display) and Manrope (body) are self-hosted through Fontsource packages. No runtime Google Fonts request is made. Font licensing files are included in their npm packages.
